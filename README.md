# ڕێگا کارگۆ · Rega Cargo

سەرچاوەی تەواوی ئەپی ڕێگا کارگۆ: نرخی خێرا، شوێنپێکردن، گومرگ و پەیوەندی، بە حەوت زمان (کوردیی ناوەندی، بادینی، ئەڵمانی، ئینگلیزی، عەرەبی، فارسی، تورکی).

ئەم ڕیپۆیە جیاوازە لە `Rega`. هیچ شتێکی ئەو ڕیپۆیە نەگۆڕدراوە. ئەمە تەنها سەرچاوەیە و بڵاونەکراوەتەوە.

## کارکردن لەسەر کۆمپیوتەر

```bash
npm install
npm run dev
```

پەڕەکان: سەرەتا، نرخ، شوێنپێکردن، گومرگ، پەیوەندی. دیزاین، لۆگۆ و زمانەکان هەر وەک خۆیانن.


## Deploy

See DEPLOY.md for the Worker, env vars (`PHONE_CODE_SECRET`, `TURNSTILE_SECRET`, `DATABASE_URL`, WhatsApp/Twilio) and migration order. Phone sign-in is off until a real provider is configured. R&L AI stays on.
