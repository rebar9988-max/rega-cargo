## Reproduced defects and smallest fixes

1. **Refund bypass of the global provider budget.** Four consume/refund cycles were accepted with a configured cap of two; the global success counter returned to zero each time. Timeout uses `Promise.race`, which does not establish provider cancellation, and invalid JSON also follows provider work. Add an internal, nonrefundable `attempts:YYYY-MM-DD` counter. Carry existing successful daily usage forward on first use. Keep successful-usage return values and visitor refunds compatible. Provider errors, timeouts and unusable results can no longer reopen the global budget.
2. **UTC rollback from delayed RPCs.** Real workerd tests showed that yesterday's refund after today's consume cleared today's cap; delayed consumes could also roll backwards. Make rollover monotonic and ignore refunds for any day other than the stored current day. Preserve the HMAC signing key and existing daily cleanup. Concurrent-call tests confirm exactly three accepted calls under a cap of three.
3. **Malformed provider envelope crash.** `choices[0].message = 42` caused the `in` operator to throw. Validate array/object envelopes before extracting content; return the existing `invalid_output` HTTP 502 contract for unusable responses. Existing OpenAI-style and legacy `response` shapes remain supported.
4. **Refund outage masks the provider error.** A thrown refund replaced the classified `model_error` response with an unhandled storage error. Make visitor refunds best effort; leave the budget consumed and preserve the original sanitized response.
5. **Origin check omitted the scheme.** `http://rl.test` passed an HTTPS handler's host-only check. Compare complete URL origins, including protocol and normalized port. Invalid/cross-origin requests fail before inference.
6. **Budget storage outage escaped the response contract.** A rejected `consume` RPC threw instead of returning a classified unavailable response. Return HTTP 503 without inference when reserving a budget slot fails; private storage diagnostics do not reach clients.

Regression tests were added and run **before the fixes**: eight AI cases and three workerd subcases failed on the original implementation; a separate budget-storage outage case also failed before its fix. All now pass. No assertions or screenshot baselines were weakened.
