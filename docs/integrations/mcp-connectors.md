# MCP connector inventory (R&L Cargo)

Verified: **2026-10-11**, from a Claude Code cloud session on branch
`claude/rl-cargo-mcp-connectors-6wqbr8`. Each status below comes from a real
read-only call made in that session, not from the connector list in the UI.
Connectors are per-account and per-session: **re-verify before relying on one**
(see "Re-verifying" at the end). No secrets, tokens or connection strings are
stored here.

Responsibilities and usage rules: [connector-responsibilities.md](connector-responsibilities.md).
Task workflows: [../architecture/ai-development-workflow.md](../architecture/ai-development-workflow.md).

## Status legend

| Status                    | Meaning                                                                          |
| ------------------------- | -------------------------------------------------------------------------------- |
| **Verified**              | Tools loaded and a read-only call returned real account data                     |
| **Verified, limited**     | Works, but plan, seat or scope limits what it can do for R&L                     |
| **Available, unverified** | Tools load, but no safe read-only call was possible without input we do not have |
| **Paid / restricted**     | Works only with credits or a paid action; do not use without owner approval      |
| **Unavailable**           | No MCP server or tools found in the session                                      |
| **Not relevant**          | Works, but has no use for R&L Cargo                                              |

## Free local alternatives already in the repo

| Need                            | Use                                                                                                                                                                                    |
| ------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Browser testing / screenshots   | Playwright with the pre-installed Chromium (`PLAYWRIGHT_BROWSERS_PATH=/opt/pw-browsers`); `npm run test:layout:geometry`; `scripts/browser-smoke.mjs`. Never run `playwright install`. |
| Database work without a real DB | PGLite fallback in `src/lib/db.ts` (used when `DATABASE_URL` is unset)                                                                                                                 |
| CI status                       | GitHub MCP (`actions_list`, `get_job_logs`) against the "Cargo quality gate" workflow (`.github/workflows/quality.yml`)                                                                |
| Error visibility                | Cloudflare Workers observability (`observability.enabled` in `wrangler.jsonc`)                                                                                                         |
