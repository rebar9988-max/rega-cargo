# Email OTP sign-in — release and live verification (2026-10-19)

Task: owner brief "R&L EMAIL OTP PRODUCTION ACTIVATION" (fix, test, deploy, verify).

## Root cause
Every gated page (`/account`, `/account/$ref`, `/request`, `/move`, `/market/sell`, `/admin`) rendered `SignInGate`, which offered only the phone dialog. Production has no WhatsApp/Twilio provider (I-3), so the dialog always showed "Phone sign-in is temporarily unavailable" and nobody could sign in.

## Change (PR [#131](https://github.com/rebar9988-max/rega-cargo/pull/131), commit `63ad833`, merge `e0778e1`)
- `migrations/0018_email_codes.sql` (additive table only).
- `src/lib/email-otp/` — `service.server.ts` (codes, limits, identity rules), `send.server.ts` (Resend), `copy.ts` (7 languages, ckb/ku `TODO(translate-review)`), `email-otp.e2e.test.ts`.
- `src/lib/auth/email-otp-plugin.ts` — Better Auth endpoints `/api/auth/rl-email/{status,send,verify}`; mints a native Better Auth session. Registered in `server.ts`; allowlisted in `src/lib/owner/http.ts`.
- `src/components/email-sign-in.tsx`, `phone-gate.tsx` (email default, phone only when its provider is configured), `sign-in-gate.tsx` (copy), `src/routes/account.index.tsx` (sign-out button).

Security properties: six digits from `crypto.randomInt`; HMAC-SHA-256 storage (`EMAIL_CODE_SECRET`, else `BETTER_AUTH_SECRET`); 5-minute expiry; 5 attempts per window; atomic 60 s resend cooldown; single atomic consumption; per-address (5/h, 10/day) and per-IP (20 sends/h, 30 verifies/h) counters plus the existing `RL_LIMIT` binding; failed delivery never activates a code. Password/provider-linked accounts, admin/super_admin roles, disabled, unverified and pending owner-invitation addresses receive the same answer as unknown addresses but no mail and no session. Same-origin enforced at the route and inside the endpoints (Better Auth's origin check skips cookie-less POSTs — proven by a test). Better Auth's stock emailOTP plugin is deliberately not mounted (it signs in any user, including the owner).

## Known limitation
