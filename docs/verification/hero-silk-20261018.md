# Homepage hero: animated red silk — 2026-10-18

Owner brief (chat): animate only the red silk behind the homepage hero headphones, like satin in a soft breeze; desktop and mobile identical; nothing else moves or changes; test at 320/360/390/430/768/1024/1440; build, deploy, verify on https://www.rlgo.net.
Base `origin/main` @ `598e93f`. Code commit `49938d4`.

## What was there

The silk was not a layer: `public/home/hero-art.webp` (504 × 496) is one flattened crop of the owner's reference (silk + headphones + podium). Animating it would have moved the headphones.

## Change

| File | Change |
|---|---|
| `public/home/hero-fg.webp` (new, 30 KB) | The same pixels with the silk cut away (headphones: BiRefNet matte, run locally, not a project dependency; podium: hand-drawn ellipse/cylinder mask). Not redrawn, recoloured or moved. |
| `src/components/hero-silk.tsx` (new) | Three layers in one stage: the unchanged `hero-art.webp` poster, a WebGL canvas (satin height field + lighting, no dependency) and `hero-fg.webp`. |
| `src/components/ref-home.tsx` | The hero art `<img>` is replaced by `<HeroSilk />` inside the same `.rl-ref-hero-art` box. |
| `src/styles/ref-home.css` | The stage takes over the image's exact positioning and fade mask; canvas and foreground are hidden until the first silk frame and under `prefers-reduced-motion`. |
| `tests/layout/premium.spec.ts` | Two specs: silk starts, stays in the art box, copy does not move, no overflow; reduced motion never starts WebGL and shows the still art. |

Behaviour: the poster is still the LCP image; the foreground and WebGL load only after `load` + idle. The silk is computed in the artwork's own pixel space with the `object-fit: cover` mapping, so phones and desktops show the same folds, light and motion relative to the headphones (one implementation; only the canvas size differs). Rendering pauses off-screen and in hidden tabs, follows live reduced-motion changes, renders at ≤ 1.5 device px per CSS px, lowers its internal resolution if frames are slow and falls back to the still art below ~23 fps at the lowest resolution. Context loss and unmount clean up (observers, rAF, context). No copy, colour token, typography, route, data or business change; no new npm dependency; service worker unchanged (pages are network-first; the new file has its own name and the existing `/home/*` cache rule).
