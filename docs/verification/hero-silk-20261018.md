## Implementation

The existing 504 × 496 `hero-art.webp` is a flattened photograph of silk, headphones and podium. It remains unchanged, initially server-rendered with its original dimensions, high priority and fade. No genuine GLB/GLTF asset exists in the repository; the product stays static. A future genuine model can occupy a separate product layer without coupling to fabric motion.

The isolated `HeroSilk` component now samples **that original photograph**, rather than generating replacement folds/colours. Smooth sine waves have 18- and 26-second periods, ≤1.45 source pixels of horizontal and ≤1 source pixel of vertical deformation, and ±1.2% sheen. There is no cycle reset. The existing 30 KB `hero-fg.webp` supplies an alpha protection mask only; it is not rendered as a replacement foreground. A four-source-pixel guard anchors the product edges, headphones, logo and podium. The transparent canvas leaves the original poster visible through protected regions. The frame edges and lower podium area are anchored too.

No animation dependency, generated model, product interaction, route, data, auth, copy, header, font or layout change. CSS transforms alone cannot deform the fabric independently inside the flattened image, so one small texture shader provides the localized deformation.

Startup waits for page load, idle time, viewport visibility and both decoded images. Initial reduced motion requests neither the mask nor WebGL. Visibility/tab changes pause drawing without resetting elapsed motion. Live reduced-motion changes return to the original poster, including a rapid-toggle race found by the new tests. Missing/failed WebGL, failed mask decoding, context loss and sustained slow rendering keep the matching poster. Observers, listeners, pending animation/idle callbacks, shaders, buffers and textures are cleaned up.

Rendering is capped at 30fps, 1.5 device pixels per CSS pixel and 300,000 backing pixels. This keeps the soft silk near the source image's native resolution; the untouched poster retains full product quality. A larger initial backing store unnecessarily taxed software rendering and was reduced after testing.

Changed runtime files: `src/components/hero-silk.tsx`, `src/components/ref-home.tsx`, `src/styles/ref-home.css`, `public/home/hero-fg.webp`. Focused tests live in `tests/layout/hero-silk.spec.ts`; the previous two duplicate premium smoke tests were removed so the existing premium spec remains identical to main. Other changes are task evidence and corrections to existing project memory.
